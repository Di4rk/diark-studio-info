Privacy Policy

You sign in on TikTok. Diark Studio receives the connected account identifier, available display name, granted permissions, and authorization tokens. It uses them to identify the account, refresh access, and send a selected MP4 when requested.

Tokens are encrypted on the local computer using Windows DPAPI. This informational website does not receive tokens or videos. TikTok processes any file you send under its privacy policy.

To disconnect, revoke app access in TikTok settings. To remove the saved authorization on this device, delete the TikTok token file in the VideoFactoryEngine folder under Windows Local AppData.
